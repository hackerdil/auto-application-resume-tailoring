# Résumé tailoring

1. Only select, reorder, shorten, conservatively combine, or rephrase verified facts.
2. Attach source fact IDs and target requirement IDs to every bullet.
3. Preserve employers, titles, dates, education, tools, metrics, and scope exactly in meaning.
4. Reject unsupported proper nouns, numbers, credentials, tools, and scale claims.
5. Regenerate a failed bullet once; then drop it with an explanation.
6. Avoid keyword stuffing, hidden text, misleading proficiency, and unreadable formatting.
7. Verify rendered PDF/DOCX content, hyperlinks, ordering, clipping, and extractability.
