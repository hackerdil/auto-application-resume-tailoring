# Application drafting

1. Separate verified facts, reasonable motivation language, and unanswered questions.
2. Cite fact IDs or saved-answer IDs for factual answers.
3. Never fabricate enthusiasm, product usage, referrals, authorization, salary, availability, or personal history.
4. Mark sensitive, legal, demographic, and ambiguous questions as requiring user input.
5. Keep answers specific, concise, and consistent across the complete application.
6. Do not submit, click consent, sign, or communicate externally.
